# Rafia Abbasi — Portfolio

This is a self-contained static portfolio served from the `docs/` folder.

## GitHub Pages

The GitHub Actions workflow at `.github/workflows/deploy-portfolio.yml` builds the resume PDF from the resume content and deploys `docs/` to GitHub Pages.

Expected URL: https://rafiaabbasi24.github.io/Portfolio/

The repository's existing application files at the root are not modified by this portfolio deployment.

## Resume

The downloadable and embedded PDF is generated by `.github/scripts/generate_resume.py` from the supplied resume content. The generated file is written to `docs/assets/RAFIA_ABBASI_AI_ML_RESUME.pdf` during the Pages build.
